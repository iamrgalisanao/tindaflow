**Reconstruction method:** each stage boundary is built by checking out the exact, already-approved file content for that stage's own paths from the previously accepted tip (`ceab7d4`, now `backup/pre-final-baseline-reconcile`) directly onto the prior stage's boundary — `git checkout ceab7d4 -- <stage-owned paths>` — rather than replaying the original interleaved commit sequence. This guarantees (a) no content is re-authored or redesigned, only relocated in the graph, verifiable via an empty `git diff backup/pre-final-baseline-reconcile <final-tip>` at the end, and (b) genuine content isolation, since a stage's boundary commit literally cannot contain a path it was never given.
